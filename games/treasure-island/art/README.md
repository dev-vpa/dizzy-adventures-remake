# Treasure Island art

Chunky pixel assets (nearest filter). Regenerate:

```bash
python scripts/generate_ti_art.py
```

| Folder | Contents |
|--------|----------|
| `backdrops/` | 512×384 biome backgrounds |
| `tiles/` | Ground / ledge textures |
| `items/` | 16×16 item icons |
| `hazards/` | Trap, fish, crab, cuttlefish |
| `npc/` | Shopkeeper, Taxman |
| `props/` | Boat, grave, totem, hatch, bubbles, décor |

Dizzy frames: `shared/sprites/dizzy/`.
